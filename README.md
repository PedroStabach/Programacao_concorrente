## Requisitos de Compilação e Execução
* **Dependências externas:** Não e necessario instalar nenhuma biblioteca externa. O projeto utiliza somente módulos nativos da biblioteca padrão do Python.

## Como rodar
1. Clone o repositório.
2. Abra o terminal a partir da raiz do projeto.
3. Em seguida utilize os comando abaixo para rodar cada um dos arquivos.

```bash
# PARTE 1: Jantar dos filósofos
python parte1-filosofos/filosofosIngenua.py
python parte1-filosofos/filosofos.py

# PARTE 2: Threads e semáforos
python parte2-semaforo/semaforo.py
python parte2-semaforo/semaforoSincronizado.py

# PARTE 3: Deadlock
python parte3-deadlock/deadlock.py
python parte3-deadlock/deadlockHierarquia.py
```
